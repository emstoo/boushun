    Standard profile

    Scan the local segment?

    Boushun sends one bounded ICMP probe to each usable address, then refreshes local evidence. Deep mode also listens briefly for mDNS/SSDP and reads configured SNMPv3 targets. It never scans ports or changes devices.

    Maximum 254 targets Timeout about 60 seconds Writes none
    ⇄

    Independent service discovery

    Discover TCP services?

    Boushun attempts a normal TCP connection to every usable IP in the selected range, including hosts that ignore ICMP. Successful connections are closed immediately without sending an application payload. These connections may appear in device or firewall logs.

    Comma-separated ports or ranges. Custom ports are added to the selected preset. Maximum 64 unique ports.

    Select a range and preset.
    Targets every usable IP Protocol TCP connect only Payload none
    ≈

    Independent service discovery

    Discover UDP services?

    Boushun sends a bounded, read-only protocol probe to every usable IP. A valid UDP reply confirms an open service. No response is reported as open or filtered and is never added to the topology.

    Known ports use a protocol-specific probe. Other ports receive an empty datagram. Maximum 16 unique ports.

    Select a range and preset.
    Targets every usable IP Rate limit 50 packets/sec Retry once on timeout
